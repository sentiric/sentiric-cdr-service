# 📊 Sentiric Cdr Service

Platformun 'Kara Kutusu' ve Muhasebecisi. Tüm olayları dinler ve faturalandırma verilerini (CDR) oluşturur.

## 🚀 Hızlı Başlangıç
```bash
go run cmd/cdr-service/main.go
```

## 🏛️ Mimari ve Mantık
* **Geliştirici Kuralları:** Gizli [.context.md](.context.md) dosyasını okuyun (AI Ajanları için zorunludur).
* **İş Mantığı ve Algoritmalar:** [LOGIC.md](LOGIC.md) dosyasını inceleyin.
* **Anayasal Konum:** [sentiric-spec/spec/services/cdr.spec.yaml](https://github.com/sentiric/sentiric-spec)
